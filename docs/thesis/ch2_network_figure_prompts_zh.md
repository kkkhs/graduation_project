# 第二章网络结构图文生图 Prompt（中文）

## 1) FCOS 结构图（中文学术风）
请绘制一张“FCOS 目标检测网络结构图（中文）”，要求：
- 画布比例 16:9，白底，学术论文风格，线条清晰。
- 模块从左到右：输入图像 -> 主干网络(ResNet) -> FPN多尺度特征(P3/P4/P5/P6/P7) -> 三个并行分支（分类分支、边框回归分支、Center-ness分支） -> 分数融合与NMS -> 最终检测框。
- 每个模块使用中文标签，字体统一为黑体或思源黑体。
- 用不同浅色区分功能块：特征提取（浅绿）、检测头（浅橙）、后处理（浅紫）。
- 在图下方增加中文注释框：“无锚框设计，降低超参数复杂度；Center-ness 抑制边缘低质量候选框”。
- 输出为可打印高分辨率（至少 2400x1350），尽量保持矢量感。

## 2) YOLO 系列结构图（中文学术风）
请绘制一张“YOLO 单阶段检测网络结构图（中文）”，要求：
- 画布比例 16:9，白底，论文插图风格。
- 模块从左到右：输入图像 -> Backbone特征提取 -> Neck(PAN/FPN特征融合) -> 多尺度检测头P3(小目标)/P4(中目标)/P5(大目标) -> 置信度筛选与NMS -> 最终检测结果。
- 所有标签中文化，箭头清晰，分支关系明确。
- 在右下角增加简短说明框：“单阶段端到端检测，速度快，部署友好；多尺度头提升小目标感知能力”。
- 配色低饱和：浅蓝、浅绿、浅橙，避免花哨。
- 输出高分辨率，适合论文直接插图。

## 3) DRENet 结构图（中文学术风）
请绘制一张“DRENet 遥感微小目标检测结构图（中文）”，要求：
- 画布比例 16:9，白底学术风。
- 主干链路：输入图像 -> 主干特征提取 -> 检测分支 -> 检测输出。
- 辅助链路（训练阶段）：从主干特征分出“退化增强分支” -> “重建分支” -> 以虚线回连到检测分支（表示训练引导）。
- 用中文标注“训练阶段引导（推理阶段不启用）”。
- 在图注释中体现核心思想：“通过退化-重建增强弱纹理微小目标表征”。
- 图风格简洁、模块对齐、箭头方向明确，适合毕业论文。

## 通用附加约束（建议追加到每个 Prompt 末尾）
- 不要英文标签，全部中文。
- 不要卡通风，不要3D，不要复杂背景纹理。
- 线宽统一，文字可读，导出 PNG 与 SVG 两个版本。
- 保留足够边距，避免插入 LaTeX 后文字裁切。
